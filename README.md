# ハロウィンおはなしメーカー

カテゴリごとに要素を選ぶと、怖くない・温かいハロウィンの短いお話が生成される、子ども向けのお話メーカーです。

公開URL（予定）: https://altogrow-ir.github.io/halloween-story-maker/

## 遊び方

- カテゴリごとに好きなものを1つずつ選びます
  - しゅじんこう（おばけのポポ、かぼちゃのカボ、くろねこ、まほうつかいのゆうちゃん、ゆうきのあるたろう、うさぎのミミ）
  - ばしょ（ふるいおやしき、まほうのもり、かぼちゃばたけ、おかしのいえ、つきあかりのおか、ほしぞらみち）
  - アイテム（ひかるランタン、まほうのかぎ、ほしのマント、にじいろキャンディ、ふしぎなちず、つきのすず）
  - であうあいて（やさしいまじょ、わらうスケルトン、おどるコウモリ、大きなフクロウ、ちいさなおばけ、うたうかぼちゃ）
  - おわり（おかしをわけあった、ともだちになった、ほしぞらでダンスした、あたたかいスープをのんだ、いいゆめをみた）
- 「📖 おはなしをつくる」を押すと、選んだ要素で4〜6文程度のお話が生成され、タイトル（例「ポポと まほうのかぎ」）も自動で付きます
- 「🎲 ランダムでつくる」を押すと、全カテゴリがランダムに選ばれてすぐにお話が生成されます
- 「🔊 よんでもらう」ボタンで、Web Speech API（`speechSynthesis`、`ja-JP`）による読み上げもできます。読み上げが使えない環境では、テキスト表示だけでそのまま遊べます
- 気に入ったお話は「❤️ おきにいりにほぞん」で保存でき、一覧から見返したり削除したりできます
- 内容は怖くない、温かい結末だけにしています。ひらがな多めのやさしい日本語で、大きなボタンを使っています

## 記録

- 作ったお話の総数と、お気に入りとして保存したお話を `localStorage` のキー `halloween-story-maker-save-v1` に保存します
- サーバーは使わず、ブラウザ（端末内）だけで完結します

## 構成

- Vite + React 19 + TypeScript（ESM、npm）
- ルート：`index.html` / `vite.config.ts`（base は `"/halloween-story-maker/"`）/ `tsconfig.json` / `package.json`
- 実装の中心：`src/App.tsx`（＋ `src/main.tsx`、`src/App.css`、`src/index.css`）
- 外部画像素材は使わず、絵文字＋CSSで表現しています

## 開発・ビルド

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # tsc -b && vite build（dist/ に出力）
npm run preview  # ビルド結果の確認
```

## 公開

- ビルド成果物を `docs/` フォルダにコピーし、GitHub Pages の公開元を `main` ブランチの `/docs` に設定して公開します（ワークフロー方式は使いません）
